--------------------------------------------------------------------------------------
// Defining an Interface

interface Area {
    double PI = 3.14;       // implicitly public, static and final
    double getArea();       // implicitly public and abstract
}

--------------------------------------------------------------------------------------
// How to use an Interface?

class Circle implements Area {
    private double radius;

    public void setRadius(double radius) {
        this.radius = radius;
    }
    public double getRadius() {
        return radius;
    }
    @Override //whats thiss
    public double getArea() {
        return PI * radius * radius;
    }
}

    Reference variable of interface can refer to an object of class
    implementing that interface.

    Area area = new Circle();
    a1.setRadius(5);        // Error: cannot find symbol

    double y = a1.getArea();      // OK: getArea() is declared in Area interface

    a1 ia a reference variable of type Area, it can refer to an object of
    circle but can only those members of circle which belongs to interface Area.


If, a class that implements an interface does not define all the methods of interface,
then it must be declared as abstract and the method definitions must be provided by
the subclass that extends the abstract class.

// Why interface is required?
->  Interfaces are used in java to achieve abstraction.

->  It is also useful in capturing similarities among unrelated classes without
    artificially forcing a class relationship.

// Polymorphism

interface I1{                       |
    void f1();                      |
}                                   |
class A1 implements I1{             |   I1 obj = new A1();
    //------                        |   obj.f1();           // this will run the f1() of A1
    public void f1(){/*------*/}    |
}                                   |
class A2 implements I1{             |   I1 obj = new A2();
    //------                        |   obj.f1();           // this will run the f1() of A2
    public void f1(){/*------*/}    |
}                                   |

// Abstract class vs Interface
->  Abstract class will have constructor but Interfaces do not have constructors.
->  Abstract class can have abstract and non-abstract methods, but interfaces can have only abstract methods
    ( surprise is waiting for you )
->  All members of an interface are public, but in Abstract class you can se only access modifiers.

->  Interface can have only static variables, but Abstract class can have instance variables.
->  Interface can jave only final variables, but Abstract class can have non-final variables as well.

// New Features
->  Before Java 8, interfaces can only have abstract methods, but from Java 8 onwards,
    you can write methods with definitions.

    BUT then how interfaces are different from abstract classes?

    There were some interfaces in Java (Before Java 8), like List which were used heavily in programming projects.

    From Java 8 onwards, some often interfaces like List were modified with extra abstract methods in it.

    So if some project was running on Java 7 and we updated Java version from 7 to 8, suddenly project should
    stop working because, classes implemented List do have definitions for extra abstract methods.


    To solve this Problem ORACLE, instead of making methods abstract, they define them as default methods

    interface I1 {
        default void f1() {             // NEED TO USE default KEYWORD******
            //------                                            known as DEFAULT METHOD
        }
    }

--------------------------------------------------------------------------------------

A class cannot extends multiple classes but can imeplement interfaces.

public class MultiInterface implements I1, I2 {
    public static void main(String[] args) {
        MultiInterface obj = new MultiInterface();
        obj.f1();                                           // ERROR: class MultiInterface inherits unrelated defaults for f1() from types I1 and I2
    }
}
interface I1 {
    default void f1() {
        System.out.println("I1");
    }
}
interface I2 {
    default void f1() {
        System.out.println("I2");
    }
}


answer, If there is defined multiple default methods with same signature,
        then the CLASS must OVERRIDE that method.


/= To solve this problem java forces to define default method in class A.

    Normally you need not to override default method of interface in the class.
